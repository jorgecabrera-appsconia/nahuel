# Portal Educativo ETP: Caída de Tensión y Dimensionamiento de Conductores
### Escuela de Educación Secundaria Técnica — Ciclo Superior

Este repositorio contiene el material pedagógico, técnico y digital completo para el abordaje del tema **Cálculo de Caída de Tensión** según las normas **AEA 90364** e **IRAM / IEC 60364**.

---

## 📂 Contenido del Repositorio

* **`index.html`**: Portal Web interactivo principal para la plataforma de la escuela. Incluye simulador de cálculo en tiempo real, visor de diapositivas, visor de cuadernillo con carátula, laboratorio de autoevaluación y tablas normativas.
* **`cuadernillo.html`**: Documento listo para imprimir en hojas A4 o guardar en PDF con **carátula formal técnica**, fotografía de la subestación transformadora, rótulo normalizado y hoja de ejercicios.
* **`presentacion.html`**: Diapositivas en pantalla completa para proyectar en aula o smart TV con notas pedagógicas para el docente.
* **`AGENTS.md`**: **Manual de transferencia técnica para agentes de IA**, con arquitectura, fórmulas inmutables, protocolo de pruebas y directivas de edición.
* **`docs/`**: Plan de clase docente en Markdown (`plan_de_clase_y_diapositivas.md`) y versión editable del cuadernillo (`cuadernillo_estudiante.md`).
* **`css/`** y **`js/`**: Hojas de estilo y motor lógico en Vanilla HTML5 / CSS3 / ES6 (100% autocontenido, funciona sin internet).
* **`images/`**: Recursos gráficos de alta resolución (`transformador.jpg`).
